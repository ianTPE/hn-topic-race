HN Topic Bar Chart Race

Each bar shows how many Hacker News posts and comments mention a term, per million, over a rolling window. It compares share of attention, so the growth of HN itself cancels out.

每個長條是滾動窗口內、每百萬則 Hacker News 貼文＋留言中提到該詞的則數。比的是佔比，HN 本身的成長不影響結果。

Race your own terms

Methodology
How mentions are counted (checked against the API)
for large result sets Algolia returns an estimate (exhaustiveNbHits=false). For example, an empty query over a full month reported 136,281 items when the real count was 358,184. So: (1) the denominator (all posts + comments that month) comes from a query with facets=_tags, which returns an exact total; (2) for the numerator, keep “Exact match” on (quoted phrase), because only then do full-month queries return exact counts. Unquoted queries can be badly underestimated (e.g. xai: actual 36,934, reported 10,913, about 3.4× too low); (3) only titles and body text are searched. By default Algolia also matches usernames and submitted URLs, which made up 43% of vercel hits and 21% of java hits in 2026-10 (links written inside a post or comment still count). Every query checks exhaustiveNbHits; if the count is an estimate, the range is automatically split into 1–2 day windows and summed.
Choice of terms
the preset categories leave out common English words and ambiguous names that inflate counts (react, angular, cursor, render, railway, swift, ruby, lit, marko, dart, nim, phi, tailwind, etc.), and keep companies separate from their products (anthropic vs claude, xai vs grok) so one comment isn’t counted twice. chatgpt / gpt is a document union: a post or comment mentioning both counts once, and so is c# / csharp. php skips items containing .php (URLs and filenames). javascript / js is a union in which js skips items containing .js (node.js, three.js, filenames) unless they also say JavaScript. Go is not in the preset: most people write “Go”, which can’t be told apart from the verb. minimax adds exclusion words to filter out the game-tree algorithm, numerical approximation, RISC-V and unrelated brands. Phrases with spaces (sublime text, together ai, cloud run) are quoted automatically so they aren’t split into common words. Use “Spot-check hits” to confirm the matches are what you meant.
Load on HN
opening this page makes no network requests. All 8 preset categories play immediately from offline data embedded in the file (a real snapshot from : 60 months starting ). Algolia is queried only when you click “Fetch data” (or press Enter in the terms field) or “Spot-check hits”: fetching the default LLM category (12 terms × 60 months) takes about 930 queries, or 1–3 minutes. Counts for completed months almost never change, so they are cached locally for 30 days, and a second fetch needs only ~15 queries (the current month). This stays well inside the Algolia HN Search API limit of 10,000 requests per hour per IP. Use “Clear cache” to force a full refetch, or “Offline data” to return to the embedded snapshot.
Since 2007, and hiring since 2012
the long-run categories are counted differently, because thousands of Algolia queries would be rude: a few SQL queries against ClickHouse’s public copy of Hacker News (), rolling 6-month window, then embedded here. The page never contacts ClickHouse. Checked on Aug–Oct 2026 against the Algolia snapshot: 33 of 38 preset terms agree within 2%; php comes out about 7% higher because a comment mentioning both “php” and a “.php” file counts here. Early words keep some noise (“rust belt” in 2009, the law degree “LLM”), and rails leaves out guard rails and payment rails. Hiring uses another unit: of the top-level comments in each monthly “Ask HN: Who is hiring?” thread (one comment, one job post), the percentage that mention the term. In job posts go, ruby and react are rarely anything else, so they can be counted; go is case-sensitive or “golang” and skips “Go to …”. Clicking a term searches that month’s thread. It starts in 2012 because two 2011 threads are missing. Full rules are in scripts/history.mjs.
“New #1” captions
generated from the data, in the long-run categories only: a term gets one when it takes first place and keeps it for at least 5 months (3 at the end of the data), so near-ties don’t flicker.
Missing data
failed requests are retried (with extra backoff on 429). If a month still fails, it is dropped from both numerator and denominator, so it can’t create a fake spike or crash. If an entire window has no data, the value is linearly interpolated from its nearest valid neighbors.
HTML-in-Canvas
the canvas has content="drawable", and each row, the title, the month, the axis labels and the timeline (a native <input type="range">) are real HTML elements marked drawable. In the paint event, drawElementImage() draws their latest snapshots, next to grid lines drawn with plain Canvas 2D. Clicks, text selection, find-in-page and screen readers keep working at the drawn positions, and captureStream() records the same pixels with their CSS. Plain HTML can’t be recorded this way, and plain canvas text can’t be selected. The 3D switch moves the same elements to a WebGL canvas: texElementSubImage2D() turns them into textures, and updateElementGeometry() gets the same perspective matrix, so tilted text is still clickable and selectable. Perspective distorts lengths, so use 2D to compare.
Axis
by default one fixed scale covers the whole period, so bar lengths compare across months. With “Dynamic axis” on, the scale follows the current leaders so early, smaller numbers stay readable; bars still start at zero, but their lengths then compare only within one month, so across months read the axis and the numbers.
Note
a month marked * is the current, unfinished month (smaller sample, but the ratio still holds). A rolling window makes new topics climb a few months late, so the default window is 3 months.
計數方式（已實測校正）
Algolia 對「結果集很大」的查詢回傳的是估算值（exhaustiveNbHits=false）——例如空查詢整月會把 358,184 筆回報成 136,281。因此 ① 分母（當月全部貼文＋留言）改用帶 facets=_tags 的查詢取得精確總數；② 分子務必開啟「精確比對」（引號片語），此時整月查詢才會回傳精確值，未加引號的查詢可能被嚴重低估（例如 xai：真值 36,934，回報 10,913，約 3.4 倍）；③ 只比對標題與內文——Algolia 預設連使用者名稱與提交網址都算命中，2026-10 的 vercel 有 43%、java 有 21% 的命中來自這兩處（寫在貼文或留言內文裡的連結仍會算）。程式每個查詢都會檢查 exhaustiveNbHits，一旦發現是估算值就自動切成 1～2 天的小視窗加總取真值。
詞的挑選
預設類別已排除會灌水的普用英文字與一詞多義的詞（react／angular／cursor／render／railway／swift／ruby／lit／marko／dart／nim／phi／tailwind 等），並把公司與其產品分開（anthropic vs claude、xai vs grok），避免一則留言被算兩次；chatgpt / gpt 以文件聯集合併，同一則貼文或留言只算一次，c# / csharp 也是；php 扣掉含 .php（網址、檔名）的則數；javascript / js 是聯集，其中 js 扣掉含 .js（node.js、three.js、檔名）的則數，除非同一則也寫了 JavaScript；預設沒有 Go 語言，因為多數人只寫 Go，和動詞 go 分不開；minimax 另加排除詞，濾掉博弈演算法、數值逼近、RISC-V 與其他同名品牌；含空白的詞組（sublime text、together ai、cloud run）會自動加引號，不會被拆成高頻普通詞。用「抽查命中」確認抓到的真的是你要的東西。
對 HN 的請求量
開啟本頁完全不會連線——8 個預設類別都直接用檔案內嵌的離線快照（ 的真實資料， 起 60 個月）立刻開始播放，切換類別也是 0 次 API 請求。只有按「抓資料」（或在詞欄按 Enter）或「抽查命中」才會向 Algolia 查詢，抓預設的 LLM 類別（12 詞 × 60 月）需要 約 930 次查詢、1～3 分鐘打完。已完成月份的計數幾乎不會再變，所以會快取在本機 30 天，第二次抓只剩 ~15 次（只重抓當月）；Algolia HN Search API 的額度是「每 IP 每小時 10,000 次」，這樣才不會把額度用完。要強制重抓可按「清除快取」，要回到內嵌快照可按「離線快照」。
2007 至今，與 2012 起的徵才
長期類別算法不同，因為用 Algolia 要打幾千次查詢：改對 ClickHouse 公開的 HN 資料庫查幾次 SQL（），滾動 6 個月，再內嵌進來。本頁不會連線到 ClickHouse。以 2026 年 8–10 月和 Algolia 快照比對，38 個預設詞有 33 個差在 2% 以內；php 高約 7%，因為同時提到「php」與「.php」檔名的留言在這裡算數。早年的詞仍有少量雜訊（2009 年的「rust belt」、法學學位 LLM），rails 已排除 guard rails、payment rails。 徵才的單位不同：每月「Ask HN: Who is hiring?」串的第一層留言（一則就是一篇徵才文）裡，提到該詞的百分比。徵才文裡的 go、ruby、react 很少是別的意思，所以可以算；go 認大小寫或 golang，並排除「Go to …」。點詞會搜尋當月那一串。2011 年缺兩個月的串，所以從 2012 年起。完整規則見 scripts/history.mjs。
「換第一」字幕
由資料自動產生，只在長期類別出現：拿到第一名並守住至少 5 個月（資料最後一段 3 個月）才算，兩者拉鋸時不會一直跳。
缺資料的處理
抓取失敗會重試（429 特別退避）；仍失敗的月份，該月會同時從分子與分母移除，因此不會出現假的尖峰或暴跌。若整個窗口都沒有可用資料，會以前後最近的有效值做線性內插。
HTML-in-Canvas
畫布設了 content="drawable"，每一列、標題、月份、刻度和時間軸（原生的 <input type="range">）都是標了 drawable 的真實 HTML 元素。在 paint 事件裡用 drawElementImage() 畫出它們最新的快照，格線則照舊用 Canvas 2D 畫。點擊、選字、頁內搜尋、螢幕報讀器都會對準畫出來的位置，captureStream() 也能連同 CSS 效果一起錄下來。一般 HTML 沒辦法這樣錄影，一般 canvas 的字則選不到。3D 開關會把同一批元素搬到 WebGL 畫布：texElementSubImage2D() 把它們變成貼圖，updateElementGeometry() 收到同一個透視矩陣，所以傾斜的字照樣點得到、選得到。透視會讓長短失真，要比較請用 2D。
數值軸
預設整段期間用同一個固定比例，不同月份的長條可以直接比長短。開啟「動態縮放」後，比例跟著當時的領先者走，早期的小數字也看得清楚；長條仍從零開始，但長短只能在同一個月內互比，跨月份請看刻度與數字。
注意
標示 * 的月份是當月、尚未結束（樣本較少，比例仍成立）；滾動窗口會讓新話題晚幾個月才爬上來，所以預設用 3 個月窗口。
